ezRouter

⚡ Ultra-Fast LLM Proxy & Router

A high-performance, single-binary LLM gateway written in pure Rust. Effortlessly pool multiple Google Gemini & Codex accounts, automate token refresh, eliminate rate limits, and compress prompts with built-in Token Saver.

⚡
Sub-ms Latency
Replaces Python LiteLLM with native Tokio + Axum speed. 0 GIL locks, <15MB RAM.
🔄
Quota Pooling
Multi-account Google Gemini & Codex rotation with automated OAuth token refresh.
🗜️
Token Saver
Compresses verbose ASTs, diffs, and logs. Cuts context usage & costs by up to 60%.
🖥️
Single Binary & UI
Standalone <9MB binary with embedded React/Vite live dashboard & SQLite engine.
